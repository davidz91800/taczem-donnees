# TacZem public aviation data

Public copies only: France INTERNATIONAL NOTAMs (FAA), official SIA SUP AIP with their PDFs, SIA AIRAC airspace volumes, the SIA AZBA forecast, validated navigation references and EMATT/EGI obstacle files, published automatically by the TacZem owner PC for TacZem Intradef (Data > Internet update). No mission, personal or account data. Content-addressed files under f/; manifest.json describes the current set.
